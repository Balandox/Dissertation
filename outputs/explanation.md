# Файлы видеомодуля для написания диссертации

Список файлов (без исходного кода), которые содержат материалы
для написания глав 3 и 4 диссертации: данные, графики, таблицы,
описания интерфейсов.

---

## Контекстный документ

| Файл | Назначение                                                              |
|---|-------------------------------------------------------------------------|
| `video_module_interface.md` | **Главный справочник.** Полное описание работы модуля и его результаты. |

---

## 1. Данные

### `outputs/video_features.csv`
**Основной результат видеомодуля.** Таблица из 969 строк × 13 колонок.
Каждая строка — один временной сегмент (окно 60 сек), содержит
6 извлечённых признаков + метку класса + метаданные.
Используется как входные данные для модулей fuzzy и ML.

### `outputs/dataset_metadata.csv`
Метаинформация обо всех 18 обработанных видеофайлах: разрешение,
FPS, длительность, маппинг на участника/класс/фолд. Пригодится
для таблицы «описание экспериментальных данных» в главе 4.

---

## 2. Графики

### `outputs/feature_distributions_boxplot.png`
**Ящики с усами (boxplot)** — распределение каждого из 6 признаков
по трём классам. Наглядно показывает медианы, квартили и выбросы.
Рекомендуется для главы 4 (раздел «Результаты извлечения признаков»).

### `outputs/feature_distributions_kde.png`
**Плотности распределений (KDE)** — более гладкое представление тех же
данных. Показывает перекрытие классов и модальность распределений.
Подходит как дополнительная иллюстрация или альтернатива boxplot.

### `outputs/feature_correlation_matrix.png`
**Корреляционная матрица** между 6 признаками. Демонстрирует связи
(EAR↔PERCLOS, blink_duration↔prolonged_blinks и др.). Полезно для
обоснования выбора признаков и обсуждения мультиколлинеарности
в главе 3.

### `outputs/feature_heatmap_by_subject.png`
**Тепловая карта** средних значений каждого признака по участникам
и классам. Показывает межсубъектную вариативность — у разных людей
разный базовый уровень EAR, частоты морганий и т.д. Важно для
обсуждения ограничений и обоснования subject-independent split.

## 3. Таблицы и отчёты

### `outputs/feature_statistics_table.csv`
Сводная таблица: среднее, мин–макс, std каждого признака по каждому
классу. Готова для вставки в текст диссертации как «Таблица N —
Статистические характеристики извлечённых признаков».

### `outputs/video_module_report.txt`
Полный текстовый отчёт со всеми числами: распределение окон по
классам, статистика признаков (среднее, медиана, std, мин, макс),
разбивка по участникам, корреляции. Удобно копировать числа в текст.

---

## 4. Документация

### `docs/video_module_interface.md`
**Контракт интерфейса** видеомодуля: формат выходных данных, описание
каждого признака (физический смысл, формула, ожидаемые значения),
маппинг классов, рекомендации по предобработке и train/test split.
Используется как контекст для чатов fuzzy/ML, а также как источник
для описания пайплайна в главе 3.

### `docs/dataset_analysis.md`
Обоснование выбора датасета UTA-RLDD: сравнительная таблица
UTA-RLDD vs NTHU-DDD, критерии выбора, ссылка для цитирования.
Материал для главы 4 (раздел «Экспериментальные данные»).
