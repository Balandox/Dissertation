# Анализ и выбор датасета для видеомодуля

## Рассмотренные кандидаты

### 1. UTA-RLDD (University of Texas at Arlington Real-Life Drowsiness Dataset)
- **Участники**: 60 человек разных этносов и возрастов (20–59 лет)
- **Видео**: 180 видеозаписей (~10 мин каждое), ~30 часов суммарно
- **Классы**: 3 — alert (0), low vigilant (5), drowsy (10)
- **Разметка**: по всему видео (self-reported, участник сам оценивал своё состояние)
- **Формат**: RGB видео, различные разрешения (записано на личные камеры/телефоны)
- **Размер**: ~111 ГБ
- **Кросс-валидация**: 5 фолдов по 12 участников
- **Доступность**: Kaggle (открытый), официальный сайт
- **Особенность**: реальная сонливость (не симулированная)

### 2. NTHU-DDD (National Tsing Hua University Drowsy Driver Detection)
- **Участники**: 36 человек
- **Видео**: ~9.5 часов
- **Классы**: drowsy / non-drowsy (покадровые аннотации для глаз, рта, головы)
- **Формат**: AVI, 640×480, ИК-камера
- **Сценарии**: BareFace, Glasses, Night_BareFace, Night_Glasses, Sunglasses
- **Доступность**: требуется License Agreement по email
- **Особенность**: симулированная сонливость (участники выполняли инструкции)

## Сравнение

| Критерий                    | UTA-RLDD          | NTHU-DDD            |
|-----------------------------|--------------------|----------------------|
| Количество участников       | 60                 | 36                   |
| Объём данных                | ~30 ч              | ~9.5 ч               |
| Реальная сонливость         | Да                 | Нет (симулированная)  |
| Число классов               | 3                  | 2 (+покадровые)      |

| Использование в литературе  | Широкое            | Широкое              |

## Решение: UTA-RLDD

### Обоснование
1. **Реальная сонливость** — участники записывали видео, когда действительно чувствовали усталость. Это даёт реалистичные микровыражения, которые невозможно точно сымитировать.
2. **3 класса** — идеально совпадают с нашей спецификацией (бодрый / предусталость / сонливый).
3. **Масштаб** — 60 участников и 180 видео обеспечивают достаточный объём для обучения и валидации.
4. **Открытый доступ** — не требуется ждать согласования лицензии.
5. **Широкое использование** — результаты можно сравнить с десятками публикаций.
